# CodexApp Runtime Laboratory

这是 CodexApp 的**实验室 Runtime 通道**，用于承载已经通过云端 Candidate 构建、但尚未晋升为稳定版的 Codex Runtime。

- 默认稳定源：`susu123oss/CodexApp-Runtime`
- 实验室源：`susu123oss/CodexApp-Runtime-Lab`
- Candidate 构建源：`susu123oss/Codex-MT`

实验室版本不会自动替换稳定版，也不会自动向普通用户提示更新。用户必须在 CodexApp 中主动选择“实验室版”并确认安装。

同一个 Runtime 版本发布后不得覆盖原有资产；如二进制或补丁变化，必须增加 revision。
